# Python for Beginners 🐍

A beginner-friendly Python learning repository containing well-structured Jupyter notebooks covering fundamental Python concepts, data structures, and practice exercises.

These notebooks were originally created as teaching material to help my friends understand Python programming concepts more effectively. Over time, I decided to make them publicly available so that anyone beginning their Python journey can benefit from them.

Whether you're completely new to programming, revising Python fundamentals, or looking for practice exercises to test your understanding, this repository aims to provide a practical and accessible learning resource.

---

## 📚 Contents

This repository currently includes notebooks covering topics such as:

* **Control Instructions**

  * Conditional statements (`if`, `elif`, `else`)
  * Loops (`for`, `while`)
  * Control flow statements

* **Strings**

  * String operations and methods
  * String manipulation techniques
  * Common string-based problems

* **Python Data Structures**

  * Lists
  * Tuples
  * Dictionaries 
  * All important methods and attributes along with operations

* **Practice Questions**

  * Beginner-level Python exercises
  * Problem-solving practice
  * Hands-on implementation to reinforce concepts

## 💻 Getting Started

### Clone the Repository

```bash
git clone https://github.com/CodeCraftsman1895/Python-for-Beginners.git
```

### Navigate to the Project Directory

```bash
cd Python-for-Beginners
```

### Launch Jupyter Notebook

```bash
jupyter notebook
```

Open any notebook and start learning at your own pace.
